# United States (North Dakota): law history in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law).

| Records | Acts | History |
| --- | ---: | --- |
| 2013 session laws | 84 | Enacted-form versions; individual official effective dates |

The [North Dakota Legislative Council](https://ndlegis.gov/) publishes these official texts. Session laws reproduce the enacted form, separately from consolidated Century Code chapters. Approval and filing dates remain in the text. The [official effective-date table](https://ndlegis.gov/sites/default/files/resource/63-2013/effective-dates-legislation/2013-effective-dates-legislation.pdf) supplies individual bill effective dates.

Coverage and consolidated histories remain incomplete. Bills with deletion markup, complex commencement, vetoes, uncertain tables, images or extraction disagreements are held. No reconstructed or corrected OCR text is included.

Existing Century Code snapshots retain the publisher currency date 2026-02-03. Constitutional records retain their original date labels. These labels do not establish individual historical commencement. Each added law is a single UTF-8 text file.
