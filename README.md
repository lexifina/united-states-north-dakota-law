# United States (North Dakota): law history in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law).

| Records | Acts | History |
| --- | ---: | --- |
| Century Code chapters and constitutional documents | 1759 | Existing current-text snapshots |

| 2023 session laws | 118 | Enacted-form versions; individual effective dates |

The [North Dakota Legislative Council](https://ndlegis.gov/) publishes the official Century Code, Constitution and session laws. The session-law records reproduce the official books in their enacted form, separately from consolidated Century Code chapters. The [November 2023 effective-date table](https://ndlegis.gov/sites/default/files/resource/68-2023/effective-dates-legislation/effective-dates-2023-legislation.pdf) supplies each included 2023 bill's effective date; approval and filing dates remain in the law text.

Coverage remains incomplete. Of 590 HB/SB entries in the regular 2023 session index, 118 are included here. The other 472 entries require assessment of deletion markup, vetoes, complex commencement, table layout or extraction disagreements. The earlier 2025 addition contains 124 of 601 indexed bills. Remaining sessions and consolidated amendment histories are incomplete. No reconstructed amendments or OCR text are included in this addition.

The existing Century Code snapshot uses the publisher's 2026-02-03 currency statement; individual amendment commencement dates have not been reconstructed. The constitutional snapshot retains its original date label. Those snapshot labels do not establish historical commencement of every provision.

Each session law is one UTF-8 text file with source line breaks. Text checks use the official book; dates use the official effective-date tables.
