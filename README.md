# United States (North Dakota): law history in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law).

| Records | Acts | History |
| --- | ---: | --- |
| Century Code chapters and constitutional documents | 1759 | Current-text snapshots retained from the existing record |
| 2025 session laws | 124 | One enacted-form version per chapter; individual effective dates |

The [North Dakota Legislative Council](https://ndlegis.gov/) publishes the official Century Code, Constitution and session laws. The session-law records reproduce the official 2025 book in its enacted form. They are separate acts, not earlier consolidated versions of the Century Code. The [October 2026 effective-date table](https://ndlegis.gov/sites/default/files/resource/69-2025/effective-dates-legislation/25.9565.03000.pdf) supplies each included bill's effective date. Approval and filing dates remain in the source text.

Coverage remains incomplete. Session laws with deletion markup, vetoes, complex commencement, uncertain table layout, images or extraction disagreements are not included in this addition. Earlier sessions and consolidated amendment histories remain to be added. No reconstructed amendments or corrected OCR text are included.

The existing Century Code snapshot uses the publisher's 2026-02-03 currency statement; its individual amendment commencement dates have not been reconstructed. The existing constitutional snapshot retains its original date label. These snapshot labels do not establish the historical commencement of every provision.

Each session law is one UTF-8 text file with source line breaks. Word-for-word checks use the official book; dates use the official effective-date table.
